# TaskFlow

Organize suas tarefas de forma simples e prática!

O TaskFlow é uma aplicação web de gerenciamento de tarefas desenvolvida para praticar conceitos de desenvolvimento web com HTML, CSS e JavaScript. Com ela, é possível cadastrar atividades, acompanhar seu estado e manter suas informações salvas no navegador.

## Demonstração

Acesse a aplicação: **[TaskFlow - GitHub Pages](https://matheusalmeida-oliveira.github.io/TaskFlow/)**

## Funcionalidades

- **Criar tarefas:** cadastre atividades com título, data, quantidade de horas e estado inicial.
- **Editar tarefas:** altere as informações de uma tarefa já cadastrada.
- **Cancelar edição:** descarte as alterações e mantenha os dados originais.
- **Concluir tarefas:** marque atividades como concluídas ou pendentes.
- **Excluir tarefas:** remova atividades da lista.
- **Pesquisar tarefas:** encontre atividades pelo título.
- **Armazenamento local:** os dados são salvos no navegador utilizando `localStorage`, permanecendo disponíveis após atualizar a página.

## Tecnologias utilizadas

- **HTML5:** estruturação da aplicação.
- **CSS3:** estilização e organização do layout com Flexbox e Grid.
- **JavaScript:** lógica da aplicação, manipulação do DOM, eventos e gerenciamento das tarefas.
- **LocalStorage:** armazenamento dos dados no navegador.
- **Git e GitHub:** controle de versão e hospedagem do projeto.

## Como executar localmente

1. Clone este repositório:

   ```bash
   git clone https://github.com/MatheusAlmeida-Oliveira/TaskFlow.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd TaskFlow
   ```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para executar a versão atual.

## Observações

- Os dados são armazenados localmente no navegador. Portanto, não existe sincronização entre diferentes dispositivos ou navegadores.
- Limpar os dados do navegador pode apagar as tarefas armazenadas.
- O projeto atualmente funciona no lado do cliente, sem integração com backend ou banco de dados.

## Objetivo do projeto

O TaskFlow foi desenvolvido como projeto de aprendizado, com o objetivo de colocar em prática fundamentos do desenvolvimento web, especialmente manipulação do DOM, eventos, funções, arrays, objetos, persistência de dados e estilização com CSS. É possível que possíveis alterações e adições sejam feitas ao projeto futuramente.
